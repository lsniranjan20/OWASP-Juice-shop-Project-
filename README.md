
# OWASP Juice Shop – Web Application Security Testing

##  Project Overview
This project demonstrates hands-on experience in web application security testing using OWASP Juice Shop. The goal was to identify and understand common vulnerabilities listed in OWASP Top 10.

##  Tools & Technologies
- Kali Linux
- OWASP Juice Shop
- Docker
- Burp Suite
- Browser Developer Tools

##  Vulnerabilities Tested
- Cross-Site Scripting (XSS)
- Broken Authentication
- Input Validation Issues
- Security Misconfiguration

##  Steps Performed
1. Deployed OWASP Juice Shop using Docker
2. Intercepted HTTP requests using Burp Suite
3. Identified vulnerable input fields
4. Tested XSS payloads
5. Documented results
